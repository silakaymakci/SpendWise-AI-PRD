# SynthFinance AI - Backend Servisi

Bu servis, Geometrik Brownian Hareketi kullanarak finansal zaman serisi verileri üretir.

## Çalıştırma Adımları
1. Gerekli kütüphaneleri yükleyin: `pip install fastapi uvicorn numpy`
2. Sunucuyu başlatın: `uvicorn main:app --reload`
3. API şimdilik `http://127.0.0.1:8000/docs` adresinde test edilebilir.
